Privacy Policy

Last updated: 22 September 2026

In short: this site collects no personal data. Recall is a design concept — there is no sign-up form, no account system, no login, and nothing on this page sends your information anywhere. Read on for the specifics.

What this site is

This website is a concept landing page for "Recall," a hypothetical invite-only study app. It exists to show what the product might look like — it is not a live service, there is no app to download, and no accounts can be created here. Nothing you do on this site is sent to a server, stored in a database, or shared with anyone.

Data this site collects

None. Specifically, this site does not:

  • Use any forms that collect names, emails, or other personal details
  • Set cookies or use browser local storage
  • Run analytics, advertising, or tracking scripts of any kind (no Google Analytics, Meta Pixel, or similar)
  • Share data with any third party, because none is collected in the first place

See the Cookie Policy for more detail on cookies and tracking specifically.

Fonts and other resources

Earlier versions of this page loaded fonts from Google Fonts' servers, which — like most remote font services — would receive your IP address on every page load. That request has since been removed: the two fonts this site uses (Fraunces and Inter) are now hosted directly alongside the site's own files, so your browser never contacts Google, or any other third-party font provider, to render this page.

This site also uses three open-source JavaScript libraries — GSAP and Lenis for scroll and motion effects, and D3 for the interactive topic map — loaded from a public code CDN (cdnjs / jsdelivr) and run entirely in your browser. They do not collect or transmit any data about you.

Applicable law

This project is based in Victoria, Australia. The relevant privacy law for a real Australian business is the federal Privacy Act 1988 (Cth) and its Australian Privacy Principles — not Victoria's own Privacy and Data Protection Act 2014, which only applies to Victorian public sector agencies, not private websites or businesses like this one. In practice, the federal Act mainly binds businesses above a $3 million annual turnover threshold (with some exceptions), so a small real version of this product might sit outside it entirely — though following the Australian Privacy Principles as best practice would still be the right call regardless of whether they're strictly mandatory.

If Recall ever became a real product

A real, invite-only study app would need to collect some information to function — at minimum an email address or invite code, cohort membership, and the questions/answers a user creates. Before any such version launched, this policy would be rewritten to describe exactly what is collected, why, how long it is kept, and how to request its deletion, in line with applicable privacy law. None of that exists today.

Children's privacy

Because this is a static demo with no data collection, no information is knowingly (or unknowingly) collected from anyone, including children. This would need dedicated attention if a real product were built for a cohort that might include minors.

Changes to this policy

If this page is updated, the "Last updated" date above will change. Since this is a demonstration project, no notification system exists to alert visitors of changes.

Contact

This is a concept project based in Victoria, Australia, without a registered business behind it, so there is no formal contact channel yet. If you have questions about this site, reach out through wherever you found it (e.g. the repository or portfolio it's linked from).
